# Resturant Management System
## Overview
      The Restaurant Management System is a software application designed to manage the daily operations of a  restaurant efficiently. It provides a centralized platform for managing customer orders, menu items, billing, payments, inventory and deliveries. The system will support different users, including the owner, manager, cashier, waiter, order taker and delivery boy. Its main purpose is to reduce the work manually, minimize errors, save time, minimize discrepancies and improve customer satisfaction.
## Scope
 
-In Scope: Menu and order management.
-In Scope: Table management.
-In Scope: Billing and payment management.
-In Scope: Inventory management.
-In Scope: Staff management.
-In Scope: Delivery management.
-In Scope: Sales and inventory reports.
